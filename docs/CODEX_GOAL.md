# Codex /goal

唯一产品目标：持续交付并公开发布一个不依赖 DCC、由 `art-delivery-profile/1` 驱动的中文资产交付工作台；审计保持只读，文件整理必须经过计划、冲突检查、明确确认、事务回滚、外部收据和执行后复检。

进度事实以 `config/goal-state.json`、其引用的 checkpoint、当前代码和测试为准。任一时刻只有一个进行中的 milestone 和一个下一切片。状态中的命令只是审阅清单，不允许被动态执行。

当前完成定义：用户无需编写命令即可记录交付信息、选择目录/Profile/启用规则，扫描、预览与审查问题；可生成可编辑的整理计划并在全量预检后明确批准执行；任何部分失败都回滚，完成后重新审计并在输入目录外保存收据。项目历史、测试素材、截图、教程、安装包和 GitHub README 均可独立复现。
