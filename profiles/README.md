# 项目规则 Profile

Profile 是 Asset Delivery Organizer 的项目规则合同，格式固定为 `art-delivery-profile/1`。同一份 JSON 可被中文桌面工作台、`ado` CLI、Python API、Skill 或 CI 使用。

## 内置模板

| 模板 | 版本 | 使用场景 | 默认规则 |
| --- | --- | --- | --- |
| `environment-standard` | 1.0.0 | 场景模型、模块件、道具 | `SM_..._v###`、B/N/R、保留 1 版 |
| `character-standard` | 1.0.0 | 角色模型与贴图 | `SK_..._v###`、B/N/R/M、保留 2 版 |

`presets/*.v1.json` 是可审阅示例，并由自动测试保证与程序内模板一致。它们不是某个商业项目的内部规范；真实项目应在“项目规则”工作区中修改项目代码、允许目录、允许格式、忽略目录、命名正则、贴图通道和版本策略，再另存为自己的 Profile。

## 保存安全

- 无效字段、重复规则或重复参数不能保存；
- 至少启用一条运行时支持的规则；
- Profile 必须保存到当前交付目录之外；
- 写入采用同目录临时文件和原子替换；
- 保存后立即重新读取，确认合同内容一致；
- 应用新 Profile 后，旧审计和旧整理计划自动失效，必须重新扫描。
